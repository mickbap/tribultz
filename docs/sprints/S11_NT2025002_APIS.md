# S11 — Referência Técnica: NT 2025.002-RTC e APIs Externas

## NT 2025.002-RTC v1.34 — Nota Técnica IBSCBS

Nota técnica da Receita Federal que define a estrutura XML do grupo IBSCBS
para NF-e (mod 55) e NFC-e (mod 65) no contexto da reforma tributária (LC 214 + LC 227).

### Estrutura XML

```
Det.Imposto.IBSCBS
├── CST (3 dígitos — 14 códigos válidos)
├── cClassTrib (6 dígitos — código de classificação tributária)
├── gIBSCBS (tributação ad valorem)
│   ├── vBC (base de cálculo)
│   ├── gIBSUF (pIBSUF, vIBSUF)
│   ├── gIBSMun (pIBSMun, vIBSMun)
│   ├── vIBS (= vIBSUF + vIBSMun)
│   └── gCBS (pCBS, vCBS)
├── gIBSCBSMono (tributação monofásica — CST 002, 620)
├── gTransfCred (transferência de crédito — CST 800)
├── gAjusteCompet (ajuste de competência — CST 811)
└── gEstornoCred (estorno de crédito — CST 830)
```

### 14 CSTs Válidos (NT 2025.002)

| CST | Grupo obrigatório | Descrição |
|-----|-------------------|-----------|
| 000 | gIBSCBS | Tributação normal (ad valorem) |
| 001 | gIBSCBS | Tributação normal com redução de base |
| 002 | gIBSCBSMono | Tributação ad rem (monofásica) |
| 070 | — | Imunidade / Isenção |
| 200 | gIBSCBS | Diferimento |
| 410 | — | Suspensão |
| 510 | gIBSCBS | Crédito presumido |
| 515 | gIBSCBS | Crédito presumido especial |
| 550 | gIBSCBS | Regime específico |
| 620 | gIBSCBSMono | Monofásico |
| 800 | gTransfCred | Transferência de crédito |
| 810 | — | Ressarcimento |
| 811 | gAjusteCompet | Ajuste de competência |
| 830 | gEstornoCred | Estorno de crédito |

### Alíquotas de referência 2026 (teste)

- **CBS**: 0,90% (0.0090) — federal
- **IBS**: 0,10% (0.0010) — estadual/municipal
- **Total**: 1,00%
- IBS split: vIBS = vIBSUF + vIBSMun

### Regras de validação implementadas

| Regra | Severidade | Descrição |
|-------|-----------|-----------|
| CST_VALID | FATAL | CST deve ser um dos 14 códigos válidos |
| CST_GROUP_MATCH | FATAL | CST requer grupo XML específico |
| CST_SEMANTIC | ALERT | CST 000 sem redução, 001 com redução |
| IBSCBS_MISSING | FATAL | Tags CBS/IBS obrigatórias |
| IBSCBS_CALC | FATAL | valor = base × alíquota (tolerância ±0.01) |
| IBSCBS_UF_CALC | FATAL | vIBSUF = vBC × pIBSUF |
| IBSCBS_MUN_CALC | FATAL | vIBSMun = vBC × pIBSMun |
| IBSCBS_SPLIT | FATAL | vIBS = vIBSUF + vIBSMun |
| IBSCBS_TOTAL | FATAL | Soma det = totais IBSCBSTot |
| LAYOUT_NFE | FATAL | emit, det, total obrigatórios |

## APIs Externas

### Conformidade Fácil — ClassTrib Lookup

- **URL**: `https://cff.svrs.rs.gov.br/api/v1/consultas/classTrib/{code}`
- **Método**: GET (público, sem autenticação)
- **Parâmetro**: `code` — 6 dígitos do cClassTrib
- **Resposta**: 200 com JSON da descrição, 404 se não encontrado
- **Implementação**: `backend/app/services/classtrib_service.py`
- **Endpoint**: `GET /api/v1/validation/classtrib/{code}` (autenticado)

### Calculadora Oficial CBS (Serpro/Receita)

- **URL**: `https://piloto-cbs.tributos.gov.br`
- **Autenticação**: OAuth 2.0 via gov.br + TLS 1.2 mutual auth (certificado digital)
- **Status**: Piloto restrito — requer credenciamento
- **Decisão**: Adiado para quando houver acesso sandbox público

### Ambientes de Homologação SEFAZ

- NF-e: `https://hom.nfe.fazenda.gov.br`
- NFC-e: `https://hom.nfce.fazenda.gov.br`
